# Artifacts Directory

This directory contains generated outputs from lab operations.

## Files

### openstack_env.json
Machine-readable environment configuration generated by `hack/openstack_up.sh`.

Contains:
- Project and user details
- Network, subnet, router IDs
- Security group configuration
- Image information
- OpenStack API endpoints

Example:
```json
{
  "timestamp": "2024-01-16T10:30:00Z",
  "project": {
    "name": "shift-lab",
    "id": "abc123..."
  },
  "network": {
    "name": "shift-network",
    "id": "def456..."
  }
}
```

### metrics.json
Installation metrics tracking all runs.

Contains array of runs with:
- `run_id`: Unique identifier
- `start_timestamp`: Start time (ISO 8601)
- `end_timestamp`: End time (ISO 8601)
- `duration_seconds`: Total duration
- `success`: Boolean success flag
- `failure_signature`: Categorized failure type
- `rollback_attempted`: Boolean
- `rollback_success`: Boolean

Example:
```json
{
  "runs": [
    {
      "run_id": "run-20240116-103000",
      "start_timestamp": "2024-01-16T10:30:00Z",
      "end_timestamp": "2024-01-16T10:35:00Z",
      "duration_seconds": 300,
      "success": true,
      "failure_signature": "",
      "rollback_attempted": false,
      "rollback_success": false
    }
  ]
}
```

### report.md
Generated metrics report from `hack/report.sh`.

Contains:
- Summary statistics
- Duration statistics
- Rollback statistics
- Top failure signatures
- Run history table

Regenerate with: `make report`

### logs/
Directory containing timestamped execution logs.

Log files:
- `openstack_up_YYYYMMDD_HHMMSS.log`
- `openstack_down_YYYYMMDD_HHMMSS.log`
- `validate_YYYYMMDD_HHMMSS.log`
- `install_YYYYMMDD_HHMMSS.log`
- `destroy_YYYYMMDD_HHMMSS.log`

## Cleanup

To clean all artifacts:
```bash
make clean
```

This removes all files but preserves directory structure.

## Backup

To backup important artifacts:
```bash
# Backup environment config
cp artifacts/openstack_env.json ~/backup/

# Backup metrics
cp artifacts/metrics.json ~/backup/

# Backup latest logs
cp artifacts/logs/* ~/backup/logs/
```

## Gitignore

This directory is gitignored to prevent committing:
- Sensitive information (credentials, IDs)
- Large log files
- Temporary data

Only this README is tracked in git.
